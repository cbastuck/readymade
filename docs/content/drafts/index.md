## How drafts are handled

- Drafts are not on the website, are not bundled with Board Assist's
  documentation, and are not indexed by the knowledge server
  (`readymade-mcp/`). What a model builds boards from stays the settled
  documentation.
- A draft that is ready moves to the section it belongs in: `concepts/`, a
  root page such as `targets.md`, or the website's own pages. Its row here
  goes with it.
- A new draft gets a file in this folder and a row in the table above.
