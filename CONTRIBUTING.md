# Contributing to Readymade

Thanks for your interest in the project — contributions are welcome.

## Before your first pull request

Readymade is licensed under AGPL-3.0. To keep the option open to offer
commercial licenses to businesses in the future (which helps fund
ongoing development of the open source project), contributors are
asked to agree to our [Contributor License Agreement](./CLA.md) before
a pull request can be merged.

This does **not** transfer your copyright — you keep it. It just grants
the project the additional rights needed to dual-license the codebase.
See [CLA.md](./CLA.md) for the full text.

(Once set up: this will be handled automatically — a bot will prompt
you to sign electronically via GitHub when you open your first PR.)
